Identifying Bears

An end-to-end image classification project — from finding a dataset on Kaggle to a working web app that classifies bears with confidence scores.

What We Built
Five steps from dataset to working app
1
Kaggle

Found data & wrote the notebook

Created a Jupyter notebook on Kaggle and used an existing public bear dataset (grizzly, black, and teddy bear images). Wrote all the training code in the notebook using fastai and PyTorch.

Platform Kaggle (free GPU)
Dataset Public bear images (3 classes)
Language Python
Kaggle Jupyter Notebook fastai
2
Kaggle

Cleaned the data

Ran verify_images() to find broken or corrupt files and removed them with Path.unlink(). Used RandomResizedCrop and aug_transforms() to augment the training data so the model sees more variation.

Bad images Detected & removed
Augmentation Crop, flip, rotate, warp
Train / Valid split 80% / 20%
verify_images aug_transforms RandomSplitter
3
Kaggle

Trained & exported the model

Used vision_learner with ResNet-18 and fine-tuned it for 4 epochs. The model learned to distinguish the three bear types. Exported the trained model as bear_model.pkl (45 MB) using learn.export().

Architecture ResNet-18
Training fine_tune(4)
Export format bear_model.pkl (45 MB)
ResNet-18 vision_learner learn.export()
4
GitHub

Created a public repo

Set up a GitHub repository with the model file, Python server, and frontend HTML. Made it public so anyone can clone the project, run it locally, and see the code.

Repo Deep-Learning-Identifying-Bears
Visibility Public
Files server.py, index.html, .pkl
GitHub Git Public repo
5
Local Mac

Built a web app

Created a Python server (FastAPI) that loads the .pkl model and accepts image uploads. Built a frontend where you drag-and-drop any image, click Classify, and see which bear it is with confidence percentages for each class.

Backend FastAPI + uvicorn
Frontend HTML + vanilla JS
URL localhost:4000
FastAPI localhost:4000 Drag & drop

App features

The web app runs locally on your Mac at localhost:4000 and includes everything needed for a complete classification workflow.

  • Drag-and-drop or browse to upload images
  • Real-time classification with confidence bars
  • History sidebar — view all past classifications
  • "+ New" button to reset and upload another image
  • Model info popup describing the project
  • Link to the public GitHub repo
🚀
To run: Open a terminal, run cd ~/Claude/bear_app && python3 server.py, then visit http://localhost:4000 in your browser. The model loads in a few seconds and you're ready to classify.
