Prediction

For educational purposes only. This model was trained on a limited dataset and should not be used for wildlife identification.

About this model

A personal project by Avinash Mohan. The image classifier is built on ResNet-18, fine-tuned to identify grizzly bears, black bears, and teddy bears using the fastai library.
